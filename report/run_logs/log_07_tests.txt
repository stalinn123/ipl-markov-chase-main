[CONCLUSION - Time Homogeneity]:
The hypothesis of strict time-homogeneity is statistically rejected (p < 0.001).
In physical cricket terms, transition probabilities shift systematically as the chase progresses:
- In the Powerplay (overs 1-6), field restrictions encourage boundary hitting with low wicket risk,
  leading to transient state persistence.
- In the Death overs (overs 16-20), absorbing transitions surge drastically: batting teams either rapidly
  reach the target (absorbing into WIN) or lose lower-order wickets slogging (absorbing into LOSS).
This is why script 06b fits a separate transition matrix for each over.

--- Test 2: Markov Property (1st-Order vs 2nd-Order Dependency) ---
Total 2-step sequences (triplets) analyzed: 15452
Likelihood-Ratio Statistic (G^2): 1440.34
Degrees of Freedom: 274
p-value: 2.3588e-157

[CONCLUSION - Markov Property]:
The strict memorylessness assumption (first-order Markov chain) is statistically rejected
in favor of a second-order chain (G^2 = 1440.34, df = 274, p < 0.001).
The test shows the previous state carries extra information, not why. It cannot separate these causes:
- Over number: this test pools all overs, so the previous state partly stands in for how late it is.
- Bucketing: states merge different scores and wicket counts, so the previous state can reveal
  where a team sits inside its bucket.
- Genuine in-match effects such as momentum or bowler spells.
Some (previous, current) state pairs are rare, so the chi-square p-value is only approximate.
No second-order chain is fitted here, so this does not show whether one would predict better.
